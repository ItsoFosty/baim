# Penka Desk V8 — Significant Far-End Lowering

The approved Penka desk V7 was checked at its real runtime placement against municipality background
V9. That composite confirmed that the counter-facing half—not the correctly planted viewport-facing
end—was reading as suspended above the floor.

A built-in image-editor context pass used the following request:

> Use case: precise-object-edit. Use Penka desk V7 as the only edit target and the municipality
> composite as a non-editable placement reference. Lower or extend only the counter-facing end until
> it visibly meets the room floor plane. Keep the complete viewport-facing half, front panel, large
> foreground legs and feet, document stack, dimensions, materials, props, and styling unchanged.

Because generative reconstruction kept redesigning the desk without correcting the grounding, the
final V8 correction uses a controlled vertical perspective deformation of the approved V7 pixels.
The counter-facing region is shifted down by 360 source pixels. The deformation tapers to zero by
source row 850, so the viewport-facing tabletop edge, apron, panel, legs, feet, and runtime placement
remain unchanged. The 1033 × 1264 canvas and transparent registration are preserved.
